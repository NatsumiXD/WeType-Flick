## 实现

- 新增独立的 `t9_1` 至 `t9_9` 上滑配置及 `t9_long_1` 至 `t9_long_9` 长按配置；不与 26 键字母混用。保留原版九键正常点击与拼音组合行为。
- 长按仍通过已定位的工具方法统一处理，实际结果必须为符号数据列表；“仅同步上滑符号”只替换对应的原始上滑项目。
- 底栏互换是独立开关，默认关闭；启用后应用于九键和中英文 26 键。确认修改后自动保存，通过远程配置监听刷新已存在的键盘，无需重启进程。
- 运行时通过属性和字段类型关系识别 KeyData / KeyboardData，区分 JSON 原始数组结构 KeyOriginData / KeyboardOriginData。布局构建方法由 DEX 调用关系识别：参数类型、getKeys 返回值和逐行 Map 写入；不写死 `o`、`a1` 等混淆名。
- 在原版布局构建完成之后交换两个按钮最终的 drawRect、hitRect、宽高、左右内边距和中心点。空间数据通过实际 Kotlin 元数据及 DEX 字段解析；不改按钮 ID、布局公式、KeyData、行列表或其他按钮。所有 Rect 原有对象引用保留，点击/长按功能仍属于各自按钮。
- 对两个按钮使用弱引用身份记录和不可变几何快照；重复应用不会再次翻转，关闭开关会立即恢复当前布局的原始位置。重新布局时丢弃旧方位的几何快照，依据原版新计算的结果互换。
- 更新定位缓存为 schema 7。启动时做 DEX 定位；已命中的上滑读取继续走弱引用缓存，没有在触摸事件中增加布局扫描或远程配置读取。
- Logo 的两个 miuix 开关以及自定义图标变更都会立即更新已存在的候选栏；退出替换或清除图片时恢复原版图案，主题变化时优先保留微信输入法新加载的原图。隐藏仍只影响图案透明度，保留点击。
- 导出格式提升到 version 3，包含九键、互换开关和同步设置；仍接受 version 1 / 2 配置。

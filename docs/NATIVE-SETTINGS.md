# 全布局互换、测试输入框与原生设置入口（1.1.9）

## 布局覆盖

互换不再依赖 `S1/S2/S3` 等字母布局标识。根据当前按钮表识别 `num` 与 `chSwitch`、`enSwitch` 或 `specialToT26Switch`；分别覆盖中英文、拼音、双拼、五笔、笔画和手写，以及对应横屏/分离布局。缺少这两个功能键的纯数字、符号界面保持原样，不把返回或 ABC 字母键当成中英开关。

继续使用原版全部计算完成后的最终几何互换，并支持当前视图即时切换和关闭恢复；不修改原始布局数据。JUnit 从用户 APK 的 18 份实际布局 JSON 提取按钮标识验证配对，英文使用 `enSwitch`，笔画和手写使用 `specialToT26Switch`。

## 输入法测试

模块首页新增本地多行输入框、“唤起输入法”和“清空”。点击输入框或唤起按钮即可使用系统当前输入法测试，输入内容只保存在页面状态中，不写入符号配置，也不上传。现有上滑、长按、Logo 和位置开关仍即时应用。

## 原生入口
